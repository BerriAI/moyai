---
name: review
description: Review code or a pull request for concrete correctness, security, recovery, and regression risks.
---

Read the actual diff and affected callers. Check identity boundaries, external
side effects, cancellation, persistence, and failure handling. Verify suspected
defects against the code; report actionable findings with locations and triggers.
Separate successful checks from untested assumptions. A rubric score or model
opinion does not replace execution evidence. Do not edit files unless requested.
