conversation notebook. Notebook paths are virtual; these tools cannot access the
API server or the user's computer. Use the advertised moyai_computer_* capabilities
for actual workspace files and commands. A notebook file is not a workspace artifact.

provide execution mechanics. In-graph subagents and Moyai's separately persisted
agent groups are distinct capabilities.
